About this tool & its limitations

This checks syllabus content against UB's official undergraduate and graduate syllabus policy pages. It automatically detects and excludes a "New Graduate Course Approval Request Form" cover form if one precedes the syllabus in the PDF.

This is a heuristic gap-flagger, not an authoritative compliance determination. A "detected" element may be a false match; a "missing" one may just be phrased unexpectedly. Always read the flagged section of the real document before acting on a finding.

The accessibility check here is deliberately degraded compared to the full desktop version of this tool (which uses veraPDF's authoritative PDF/UA-1 / ISO 14289-1 validator). This browser-only version can only check, using the PDF's own tag structure where present:

  • Whether the PDF is flagged as a tagged PDF at all
  • Whether the document has a title set in its metadata
  • Whether the document appears to declare a language (approximate, byte-level check)
  • Images/figures with no alt-text description
  • Hyperlinks with no accessible description text
  • Tables with inconsistent row/column structure

It does not check font embedding, table header scope attributes, or full per-element tagging coverage the way the desktop veraPDF-based tool does. Treat a clean result here as "no obvious problems found," not "accessible."

Client-side only — built with pdf.js and docx.js. Source: UB Academic Affairs internal tooling.
